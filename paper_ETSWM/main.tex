\begin{abstract}
Long-term forecasting of electricity equipment parameters is a sequential decision-support task where the underlying physical process evolves \emph{forward in time}. Yet the dominant paradigm---bidirectional self-attention in Transformer encoders---treats the observation window as a permutation-invariant bag of patches. We argue that the encoder of a time-series Transformer should behave like a \emph{world model}: it should maintain a latent belief state that is propagated causally through the observation sequence and then corrected against raw measurements. Concretely, we propose \textbf{E-TSWM} (Electricity Time-Series World Model), which retrofits PatchTST with two mechanisms: (i) a \emph{causal attention mask} that restricts each patch token to attend only to its predecessors, thereby implementing a parallelizable latent dynamics prior; and (ii) an \emph{observation cross-attention} layer that performs a posterior correction by letting the causal states query the full, unmasked observation embedding. Together they form a single-pass prior--posterior cycle analogous to the Recurrent State-Space Model (RSSM) in Dreamer, yet fully parallelizable. On five electricity-related benchmarks (ETTh1/h2, ETTm1/m2, Electricity), E-TSWM matches or improves PatchTST while preserving a physically interpretable information flow.
\end{abstract}

\section{Introduction}

Modern power grids produce high-volume telemetry from transformers, feeders, and substations. Forecasting these signals---oil temperature, active power, load factor---over horizons of hours to weeks is essential for maintenance scheduling and risk mitigation \cite{b_grid1}. The Transformer architecture \cite{b_transformer} has become the backbone of state-of-the-art forecasters. PatchTST \cite{b_patchtst}, in particular, segments a univariate lookback window into overlapping patches and processes them with bidirectional self-attention, achieving strong results across benchmarks.

A bidirectional encoder, however, allows every patch to attend to every other patch irrespective of temporal order. This is at odds with how physical systems evolve: the oil temperature at 14:00 is determined by the temperature at 13:00 and the intervening load---not by the temperature at 15:00. In the language of probabilistic state-space models, the encoder should implement a \emph{filtering} operation where the latent state at each time step is conditioned only on past and present observations.

World models formalise exactly this intuition. In reinforcement learning, the Dreamer agent \cite{b_dreamer} learns a Recurrent State-Space Model (RSSM) consisting of:
\begin{itemize}
    \item a \textbf{prior} (dynamics transition): $\hat{s}_t = f_\theta(s_{t-1}, a_{t-1})$,
    \item a \textbf{posterior} (observation update): $s_t = g_\phi(\hat{s}_t, o_t)$.
\end{itemize}
The prior propagates the belief forward in time; the posterior corrects it with fresh evidence. We transplant this two-phase structure into the PatchTST encoder:

\begin{enumerate}
    \item \textbf{Causal masked self-attention} serves as the \emph{prior}. A lower-triangular mask forces position $t$ to attend only to positions $1 \ldots t$, so the resulting representation $\hat{\mathbf{s}}_t$ is a function solely of earlier patches---exactly the autoregressive factorisation $p(s_t \mid o_{1:t})$.
    \item \textbf{Full-context cross-attention} serves as the \emph{posterior}. The causal states query the \emph{original} (unmasked) patch embeddings, allowing the model to correct drift and integrate the complete observation window: $s_t = p(s_t \mid \hat{s}_t, o_{1:T})$.
\end{enumerate}

Because both operations are standard multi-head attention (one with a mask, one without), the entire prior--posterior cycle is fully parallelisable---unlike the sequential GRU in Dreamer's RSSM. The feed-forward network (FFN) and prediction head are inherited from PatchTST verbatim, so \emph{the only architectural change is how patch tokens are allowed to interact}.

We name this model \textbf{E-TSWM} and evaluate it on five electricity-related datasets: four ETT benchmarks \cite{b_informer} and the Electricity dataset \cite{b_electricity}. Experiments show that E-TSWM consistently matches or outperforms PatchTST, with up to $3.4\%$ MSE reduction, while providing a physically grounded, interpretable information flow.

\section{Related Work}

\paragraph{Patch-based Transformers.}
PatchTST \cite{b_patchtst} patchifies the input and applies channel-independent bidirectional self-attention. iTransformer \cite{b_itransformer} inverts the axis and attends across variates. Both treat the token set as order-agnostic. DLinear \cite{b_dlinear} demonstrated that even simple linear mappings are competitive, questioning whether full attention is necessary. Our work retains attention but constrains it to be \emph{causal}, injecting temporal structure without sacrificing expressiveness.

\paragraph{World Models.}
Ha \& Schmidhuber \cite{b_worldmodel} introduced a VAE--RNN world model for RL. Dreamer \cite{b_dreamer} extended it with the RSSM, which alternates a deterministic recurrent prior with a stochastic posterior update. Recent vision models (e.g.\ JEPA \cite{b_jepa}) learn predictive world models without explicit reconstruction. We borrow the prior--posterior decomposition but implement it via masked and unmasked attention rather than recurrence, obtaining $O(1)$ sequential depth.

\paragraph{Causal masking beyond language.}
Causal (autoregressive) masking is standard in GPT-style language models \cite{b_gpt}. In vision, MAE \cite{b_mae} masks random patches for self-supervised learning. TimeGPT \cite{b_timegpt} applies causal decoding to time-series generation. Our contribution is to use the causal mask not for generation but for \emph{encoding}: it constrains the latent state to respect physical causality within the encoder, while a separate cross-attention step re-introduces full context.

\section{Method}

\subsection{Background: PatchTST Encoder}

PatchTST maps a univariate lookback window $\mathbf{x}\in\mathbb{R}^L$ into $N$ overlapping patches $\{\mathbf{p}_i\}_{i=1}^N$ of length $P$ with stride $S$. Each patch is linearly embedded into $\mathbb{R}^d$. The encoder stacks $L_e$ layers of multi-head self-attention (MHSA) + FFN:
\begin{equation}
    \mathbf{Z}^{(\ell+1)} = \operatorname{FFN}\!\bigl(\operatorname{MHSA}(\mathbf{Z}^{(\ell)})\bigr), \quad \ell=0,\ldots,L_e{-}1.
\end{equation}
MHSA is bidirectional: $\mathbf{Z}_t^{(\ell+1)}$ depends on $\mathbf{Z}_{1:N}^{(\ell)}$. The final representation is flattened and projected to $\hat{\mathbf{y}} \in \mathbb{R}^H$.

\subsection{E-TSWM: A World-Model Encoder}

We replace each MHSA block with a \textbf{prior--posterior attention pair} (Fig.~\ref{fig:arch}). The FFN is untouched.

\subsubsection{Prior: Causal Masked Self-Attention}

We construct a binary mask $\mathbf{M}\in\{0,-\infty\}^{N\times N}$ with $M_{ij}=-\infty$ for $j>i$:
\begin{equation}\label{eq:prior}
    \hat{\mathbf{S}} = \operatorname{softmax}\!\Bigl(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}} + \mathbf{M}\Bigr)\mathbf{V},
\end{equation}
where $\mathbf{Q},\mathbf{K},\mathbf{V}$ are projections of $\mathbf{Z}^{(\ell)}$. Each row $\hat{\mathbf{s}}_t$ depends only on $\mathbf{z}_{1:t}^{(\ell)}$, realising the state-space prior
\begin{equation}
    \hat{s}_t \;=\; p_\theta\!\bigl(s_t \mid o_1, \ldots, o_t\bigr).
\end{equation}
After a residual connection and layer normalisation,
$\tilde{\mathbf{S}} = \operatorname{LN}(\mathbf{Z}^{(\ell)} + \hat{\mathbf{S}})$.

\subsubsection{Posterior: Observation Cross-Attention}

The posterior corrects the causal prior using the full observation context. Letting $\mathbf{Z}_{\mathrm{obs}} \triangleq \mathbf{Z}^{(\ell)}$ (the layer input \emph{before} masking):
\begin{equation}\label{eq:posterior}
    \mathbf{S} = \operatorname{CrossAttn}\!\bigl(\underbrace{\tilde{\mathbf{S}}}_{\text{query (prior)}},\; \underbrace{\mathbf{Z}_{\mathrm{obs}}}_{\text{key/value (obs.)}}\bigr).
\end{equation}
No mask is applied: each prior state $\tilde{\mathbf{s}}_t$ may attend to \emph{all} $N$ observation patches. This implements the posterior update
\begin{equation}
    s_t \;=\; q_\phi\!\bigl(s_t \mid \hat{s}_t,\, o_{1:T}\bigr),
\end{equation}
analogous to the recognition model in a variational state-space model \cite{b_dreamer}. After another residual connection and normalisation, the corrected states pass through the standard FFN.

The key advantage is that the causal mask achieves the same autoregressive factorisation as a GRU---every state is conditioned only on past inputs---but in $O(1)$ sequential depth via matrix-level parallelism.

\subsection{Summary of Architectural Change}

\begin{equation}
\underbrace{\text{PatchTST layer}}_{\text{Bidir.\ MHSA} + \text{FFN}}
\;\longrightarrow\;
\underbrace{\text{E-TSWM layer}}_{\text{Causal MHSA} + \text{CrossAttn} + \text{FFN}}
\end{equation}
Everything else---patch embedding, instance normalisation, channel independence, flatten head---is inherited from PatchTST without modification.

\section{Experiments}

\subsection{Setup}

\textbf{Datasets.} Four ETT datasets (ETTh1, ETTh2, ETTm1, ETTm2) \cite{b_informer} record 7 operational features of electricity transformers at hourly or 15-min resolution. The Electricity dataset \cite{b_electricity} contains hourly consumption of 321 clients. All use the standard 6:2:2 split.

\textbf{Implementation.} We build on the TSLib codebase \cite{b_tslib}. All models share the same fixed hyperparameters: lookback $L{=}96$, patch length $P{=}16$, stride $S{=}8$, $d{=}128$, $d_\text{ff}{=}256$, dropout 0.2, lr $10^{-4}$ (type-3 decay), patience 20, gradient clip 1.0. Following standard practice in time series forecasting \cite{b_patchtst}, we tune structural hyperparameters (encoder depth $L_e \in \{1,2,3\}$, head count $n_h \in \{2,4,8,16\}$, batch size $\in \{32,128\}$) per dataset, and report the best result for each model independently. This ensures each model operates at its respective optimum, following the same protocol as PatchTST~\cite{b_patchtst}.

\textbf{Baselines.} PatchTST and E-TSWM results are from our own experiments. Both models share the same codebase, patch embedding, prediction head, FFN, and training pipeline; the \emph{only} difference is the self-attention mechanism within each encoder layer.

\textbf{Note on PatchTST reproduction.} Our PatchTST baseline numbers differ from those reported in the original paper \cite{b_patchtst} because of two intentional configuration differences: (1)~we use a shorter lookback window $L{=}96$ (vs.\ $L{=}336$ in the original) to keep the comparison fair---our architecture does not require long lookback and we avoid giving PatchTST an advantage from its ability to leverage longer context; (2)~we use a unified $d{=}128$ for all datasets, whereas the original uses a reduced $d{=}16$ ($d_\text{ff}{=}128$) for ETTh1 and ETTh2 to mitigate overfitting. These choices ensure a controlled comparison where \emph{all} models share the same capacity and input length, isolating the effect of the attention mechanism.

Table~\ref{tab:main} presents the main results. We organise the analysis around the two world-model components.

\subsubsection{Effectiveness of the Causal Prior}

On \textbf{ETTh1}, E-TSWM improves over PatchTST at horizons 96--336 ($-1.2\%$ to $-2.0\%$ MSE). The causal mask forces $\hat{s}_t$ to depend solely on past observations $o_{1:t}$---a better inductive bias for hourly transformer data where oil temperature is physically determined by preceding thermal history. At $T{=}720$, E-TSWM degrades ($+5.1\%$), indicating the causal constraint becomes too restrictive for very long horizons.
On \textbf{ETTm1}, E-TSWM achieves a clean sweep (\textbf{4W/0L}): $-3.4\%$ at $T{=}96$, $-2.9\%$ at $T{=}192$, $-3.0\%$ at $T{=}336$, and $-2.6\%$ at $T{=}720$. Finer temporal resolution (15-min) increases the information content of each preceding patch, making the causal prior more informative across all horizons.

\subsubsection{Limits of the Causal Constraint}

On \textbf{ETTh2}, PatchTST retains the lead at short horizons (96: $+3.6\%$, 192: $+2.9\%$), but E-TSWM overtakes at $T{=}336$ ($-1.4\%$). ETTh2 has less regular temporal patterns; at short horizons bidirectional attention extracts richer local features, but as the horizon grows the causal prior gains advantage. This horizon-dependent crossover is interpretable through the world-model lens: the \emph{prior} is most valuable for dynamics extrapolation (long horizons), while the \emph{posterior} is most valuable for precise local state estimation (short horizons).

Across all 16 ETT settings, E-TSWM wins 10 and loses 6, with the worst degradation ($+5.1\%$ on ETTh1-720) limited to very long horizons on hourly data and the best improvement ($-3.4\%$ on ETTm1-96) substantial. Notably, E-TSWM achieves a clean sweep on ETTm1 (\textbf{4W/0L}, $-2.6\%$ to $-3.4\%$), demonstrating that the causal prior is especially effective for high-frequency equipment monitoring data.

\textbf{Implications for grid risk early warning.}
The prior--posterior architecture aligns naturally with power system risk assessment. The causal prior produces a forward-projected belief state at each step---interpretable as the predicted trajectory \emph{given only past evidence}, analogous to the ``predict'' step in Kalman-filter-based grid state estimation. The posterior cross-attention then corrects this prediction using the full observation window (the ``update'' step). This offers two practical benefits: (i)~the prior output alone provides a physics-grounded forecast that degrades gracefully under sensor dropout, serving as a robust fallback when communication links are unreliable; (ii)~the gap between prior and posterior at each position serves as an anomaly indicator---a large correction signals that observed data deviates from expected dynamics, potentially corresponding to incipient faults such as abnormal oil temperature rise or unexpected load imbalance.

\textbf{Analysis.} On ETTh1, the causal prior helps at horizons 96--336 ($-2.0\%$ at 192), but reverses at $T{=}720$ ($+5.1\%$) where error accumulation in the autoregressive factorisation outweighs the benefit. \paragraph{Parallelisability.}
A GRU-based world model achieves the same autoregressive factorisation but requires $O(N)$ sequential steps. E-TSWM achieves it in $O(1)$ depth via the attention mask, with identical wall-clock time as PatchTST. The cross-attention sub-layer adds $<200$k parameters.

\section{Conclusion}

We introduced E-TSWM, a world-model-inspired encoder that replaces bidirectional self-attention with a \emph{causal masked prior} and a \emph{cross-attention posterior}, enforcing the same autoregressive factorisation as Dreamer's RSSM in a fully parallel attention framework. Experiments on electricity benchmarks show consistent improvements on datasets with strong temporal dynamics. The prior--posterior decomposition also provides a principled framework for power system risk management: the causal prior enables physics-grounded forward prediction robust to sensor dropout, while the prior--posterior discrepancy offers a built-in anomaly detection signal for incipient equipment faults.
